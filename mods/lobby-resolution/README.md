# 大厅分辨率 mod（lobby-resolution 1.0.0）

把游戏大厅（前端）的窗口调到你指定的分辨率，默认 **1920×1080**。启动器的配置里没有这个选项，这里补上。

## 配置

`mods\lobby-resolution\config.json`，改完重启 worker 生效：

| 键 | 默认 | 含义 |
| --- | --- | --- |
| `enabled` | `true` | 关掉整个 mod |
| `width` / `height` | `1920` / `1080` | 目标**画面**尺寸（不含标题栏和边框），200–7680 |
| `lobby_only` | `true` | 只在大厅（前端）生效；`false` = 任何界面尺寸不符就调 |
| `poll_seconds` | `2.0` | 检查间隔；游戏把窗口改回去时会被重新调大 |

## 原理

只调 **Win32 窗口**：用 `EnumWindows` 找到游戏主窗口，`SetWindowPos` 把**客户区**改成
1920×1080（先按边框算好窗口大小）。窗口化模式下引擎收到 `WM_SIZE` 后会按新客户区重建
视口，所以渲染分辨率就是 1920×1080。

- 不修改任何游戏文件，不读写游戏内存（除非要判断"现在是不是大厅"）；
- 不需要 ProcessEvent 钩子，和 AI worker / 鞭尸 mod 都不冲突；
- R10 的封印无关：这是普通的窗口调用，不是游戏脚本；
- 大厅判定用自带的内存读取器读 `WorldInfo → Game` 的类名（`SFEntryGame*`），读不到就
  退化成"尺寸不符就调"，并在日志里说明。

## 安装与使用

1. 解压到游戏根目录，得到 `<游戏>\mods\lobby-resolution\`；
2. 双击 `安装.cmd`，游戏目录里会出现 `启动-大厅分辨率.cmd`；
3. **先启动游戏**，再双击那个 `.cmd`。worker 在后台运行，游戏关掉后自己退出。

日志在 `logs\lobby-resolution-<日期>.jsonl`：`ready → window → resized`，`resized` 里有
调整前后的客户区尺寸；`status` 每 30 秒一条。

## 边界

- 只在窗口化模式有意义（客户端本来就以 `-windowed` 启动）；独占全屏由游戏自己的设置管。
- 调整的是**窗口客户区**，任务栏、标题栏不在内。
- 如果显示器比目标分辨率小，窗口会超出屏幕（Windows 允许），这时 `resized` 里的 `actual`
  仍是 1920×1080，但画面会有一部分看不到。
