## 这份包是什么

- **运行时补丁**，不改游戏文件：复用客户端自带的 `runtime\tools\local_battle_bridge.py` 桥，在游戏进程里读数据、施加 `AddImpulse`。
- **三层判据**，都来自游戏自己：枪读武器的命中记录；投射物读飞行折线 + 销毁时机；近战读状态位/弹药变化。
- **只对尸体生效**：`Health <= 0` 的 pawn 才会收到冲量。
- **可观测**：所有判定写单行 JSON 日志，`corpse-hit` / `melee-hit` / `projectile-hit` / `settled` 能把"判没判中、推了多远"完整还原。

## 快速排错（30 秒版）

| 症状 | 先看 |
| --- | --- |
| 双击启动器没反应 | 先看 `logs\launcher.log`（见 [`04-排错.md`](04-排错.md) §0 与 [`06-日志字段.md`](06-日志字段.md) §6.5）。1.10.3 起启动器一定先确保游戏在跑，再处理 worker |
| 弹窗 `worker 启动后立刻退出了（exit …）` | `logs\worker-console.log` / `logs\crash.log`；旧版本见 [`07-版本历史.md`](07-版本历史.md) 的 1.10.1 条目 |
| 卸载报"文件被占用" | 关掉 Obsidian/编辑器再试（[`04-排错.md`](04-排错.md) §0 最后一行） |
| 日志没有 `ready` | 游戏没开 / 被最小化 / 桥装了但主线程没推进 |
| 关游戏后日志最后一行是 `game-exit` | 正常：1.10.3 起 worker 跟着游戏一起退出（旧版会空转到 `idle-exit`） |
| 日志停在 `waiting-boot` | 游戏还在加载（1.10.2+ 会一直等）。进到大厅/对局后应出现 `booted` → `ready`；旧版这里会写 `fatal` 直接退出 |
| 只有 `shot-miss`、没有 `corpse-hit` | 这一枪没打中尸体（`impacts[]` 里是墙/地面/活人） |
| 有 `corpse-hit` 但 `settled.moved` 很小 | 力度不够或尸体卡在几何里，调 `strength` |
| 投掷完全没反应 | `projectile: true`？`projectile_radius` 是否被改小 |
| 按 E 没反应 | 3 米内有没有尸体；`drag: true`；日志里是 `drag-start` 还是 `drag-none` |
| 拖拽发抖/飞出去 | [`05-用户手册.md`](05-用户手册.md) §9.3 |
