# 02 · 数据结构与偏移

> 所有数值都在 `SF2-Offline-20261016` 的客户端上实测。游戏一旦换版本，先跑 `tools\selftest.py`，
> 再看本文最后一节"如何重新测量"。运行库的 Reader 会先校验 `runtime\test-client\Binaries\Win32\sf2.exe` 的 sha256，
> 版本不对会直接拒绝（`Client version mismatch`），不会静默读到错数据。

## 1. 全局入口

| 名称 | 地址 | 说明 |
| --- | --- | --- |
| `GWorld` | `0x179B2F4` | `UWorld*`，每张图/每次换图会变 |
| `GObjects` | `0x17882D0` | `TArray<UObject*>`：`[ptr, count, capacity]` 各 u32 |
| `GNames` | `0x1775EF0` | `TArray<FNameEntry*>` |
| `ProcessEvent` 入口 | `0x6008D0` | 原字节 `56 8b f1 8b 0d f4 b2 79 01`；桥把它改成 `E9 rel32` |

取当前世界：

```
world  = u32[GWorld]
level  = u32[world + 0x50]          # UWorld.PersistentLevel
actors = u32[level + 0x3C]          # ULevel.Actors: [ptr, count, capacity]
```

一次 bulk 读就能拿到全部 actor（实测约 250~260 个，耗时 < 0.1 ms），**不要**用 GObjects 增量扫描：
换图后对象表重建，游标会失明（历史 bug），而且整表遍历要 3.3 秒。

> 不必硬编码信任本文。

## 3. 核心结构：`RifleHitResult`

`ASFWeap_Bullet.HitResult`（偏移 `0xC90`，struct 名 `RifleHitResult`，`StructProperty.size = 36`）：

| 相对偏移 | 绝对偏移 | 字段 |
| --- | --- | --- |
| `+0x00` | `0xC90` | `TArray<FImpactInfo> ImpactInfos` |
| `+0x0C` | `0xC9C` | `TArray<FImpactInfo> PenetrationInfos` |
| `+0x18` | `0xCA8` | `TArray<float> DamageScale` |

TArray 头是 12 字节：`ptr(u32), count(u32), capacity(u32)`。

`FImpactInfo`（元素 80 字节）：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| `+0` | `AActor*` | 被打中的对象 |
| `+4` | FVector | 命中世界坐标 |
| `+16` | FVector | 命中面法线 |
| `+28` | FVector | 子弹方向 |
| `+40` | FVector | 射线起点 |
| `+52` | 28 字节 | 引擎内层 `FImpactInfo.HitInfo` |

实测的一份原始记录（打中桶后打到地板，count=2）：

```
[0] actor=SFKActorNoSync_12          loc=(-5686.4, -932.2, 11358.1) n=(0.8,0.3,0.4)  dir=(-0.48,-0.83,-0.28)
[1] actor=StaticMeshCollectionActor_6 loc=(-5697.3, -951.2, 11351.6) n=(0,0,1)         dir 同上
PenetrationInfos: 1 条，穿出点 (-5693.4, -944.4, 11353.9)
```

**判断"这一发是不是新的一发"**：`(list, actor, round(loc,2))` 组成签名，与上一发比较；
配合"弹匣递减"触发，可以做到不重复、不遗漏。

`DamageScale` 是 **float 数组**，不要按 80 字节读（会把 TArray 头当成结构体，得到垃圾）。

## 4. 施加冲量

`Engine.PrimitiveComponent.AddImpulse` 经桥调用时，参数区是 36 字节：

```python
struct.pack('<3f3fQ?3x', impulse_x, impulse_y, impulse_z,
                          point_x, point_y, point_z,
                          0,        # BoneName = NAME_None，按位置分布力
                          False)    # bVelChange
```

- 对象指针传 `pawn.Mesh`（USkeletalMeshComponent）。
- `bVelChange=True` 在这一版**无效**（实测位移 0.04~5 cm 且是噪声），必须用冲量。
- 调用前不需要 `WakeRigidBody`：PhysX 会自行唤醒睡眠中的布娃娃。

## 5. 冲量标定（实测）

同一具尸体（`SFCPawn_0`，mesh `0x6003f000`）重复施加冲量，测 0.35 秒后 mesh 平移：

| 冲量 | 位移 cm |
| --- | --- |
| 100 | 0.43 |
| 200 | 1.33 |
| 400 | 0.94 |
| **800** | **13.41** |
| 1600 | 91.59 |
| 3200 | 94.4（饱和） |

结论：静摩擦门槛约 **600**，600 以下完全推不动；1600 以上像被车撞；可用区间 700~1400。
默认取 `strength = 700`（轻微、稳定），`max_impulse = 1200`。

> 早期版本用 2000，45 发里位移 12~880 cm，多数超过 40 cm，用户反馈"推力过大"。

## 6. 已排除的信号（附实测数字，别再试）

| 信号 | 实测 |
| --- | --- |
| `Engine.Actor.Trace` / `FastTrace`（桥调用） | 参数回填正常，返回值恒 0；垂直向下 40000 单位穿过地板也"没碰到" |
| `SFWeap_Bullet.FireEndTrace(bIsTest=True)` | 返回 `Start + Dir*100000`，即未命中的硬上限 |
| 关卡 actor 表 diff | 25 秒交火 0 新增；全量约 255 个 actor |
| Decal / DecalComponent | `ActiveDecals` count=0、`PoolDecals` count=0、8 个实例全零 ⇒ 系统未启用 |
| 全 GObjects 扫描 | 180,989 个对象、5,188 ms，无法每发执行 |
| `SFPawn.LastTakeHitInfo` / `LastHitTime` | 尸体中弹后 7 发内零变化 |
| Hook `ProcessEvent`（`0x6008D0`） | 命中链不经过它（观察 8 发命中，零事件） |
| 骨骼球/胶囊几何近似 | 假阳性（无遮挡判断）+ 漏判（门槛 0.8×半径）同时存在 |

## 7. 如何重新测量（换版本时）

1. 跑 `tools\selftest.py`，它会打印：能否找到游戏、世界/关卡指针、所有 pawn 的名称/血量/mesh/位置、武器与弹匣、上一发命中记录。哪一项是 0 或异常，就说明哪个偏移废了。
2. 用运行库的 `NativeAPI` 反查属性偏移，不要靠猜：

   ```python
   from sf2mod import attach
   root = attach.game_dir(); battle, route, mt = attach.load_runtime(root)
   api = route.NativeAPI(battle.Bridge(attach.find_pid(root)))
   api.properties['SFGame.SFPawn.Health']        # {'address','class','size','dim','offset',...}
   api.fields('SFGame.SFWeap_Bullet.ProcessInstantHitSub')   # 参数表
   ```

   `NativeAPI` 会遍历全部对象并解析路径，首次约 2~3 秒。
3. `RifleHitResult` 的结构布局可以从 `api.properties['SFGame.SFWeap_Bullet.HitResult']` 拿到 `size=36`，再读它的 `StructProperty` 子成员（子属性指针在属性对象 `+0x84`）。
4. `ProcessEvent` 入口字节（`EXPECTED`）如果变了，`attach.py` 会拒绝安装；先用 PE 工具或内存扫描确认新入口，再更新 `HOOK` 与 `EXPECTED`。

## 8. 弓 / 近战新增偏移（1.1.0 实测）

| 名称 | 偏移 | 类型 | 备注 |
| --- | --- | --- | --- |
| `SFGame.SFPawn_Player.DoingExigencyAttack` | `0xED8` | BoolProperty，掩码 `0x8` | 挥击期间为 1，按字节读再按位与 |
| `Engine.Actor.Velocity` | `0x180` | FVector | 投射物方向来源 |
| `Engine.SkeletalMeshComponent.SpaceBases` | `0x230` | TArray | 每骨 32 字节，平移在 `+16`，组件空间 |
| `Engine.SkeletalMeshComponent.LocalToWorld`（矩阵） | `0x170` | FMatrix 64 字节 | 平移在 `+48`（M[12..14]） |
| `SFGame.SFProj_Arrow.bStucked` | `0x404` | BoolProperty | **不可用**：飞行途中会乱翻 |
| `SFGame.SFProj_Arrow.AttachedTo` | `0x408` | ObjectProperty | 实测命中尸体时仍为 null |
| `SFGame.SFProj_Knife.bStucked` | `0x3E8` | BoolProperty | 同上，不可用 |
| `SFGame.SFProjectile.VictimActor` | `0x318` | ObjectProperty | 命中尸体时仍为 null |
| `SFGame.SFWeap_MeleeSwing.SwingPawns` | `0xD08` | TArray（元素 116 字节，`Pawn` 在 `+4`） | 挥刀时**不产生实例**，留着备查 |

投射物类名匹配：`SFCProjectile` 前缀（箭是 `SFCProjectileBowArrow`）或 `SFProj_` 前缀。
不要在 `SFGame.upk` 里找 `SFCProjectileBowArrow`——它是 `SFGameContent.upk` 里的蓝图类，
运行期以 `SFCProjectile*` 出现在关卡 actor 表里。
